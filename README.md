**Варіант 5.** Програма для розрахунку вартості фарбування стін кімнати.

## Запуск

```
python paint_cost.py
```

Програма запитує довжину, ширину й висоту кімнати, площу вікон і дверей,
вартість фарби за літр та кількість шарів, після чого виводить площу стін,
потрібну кількість фарби та вартість фарбування.
